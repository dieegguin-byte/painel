# Operação Bahia V4 — protótipo isolado

Esta pasta é o laboratório da V4. **Não substitui o app atual.**

## Nesta primeira entrega

- arquitetura formal;
- navegação V4;
- tela inicial `Hoje`;
- bloco `Precisa de você` para exceções humanas;
- captura rápida sem conceito de Caixa;
- módulos reservados para evolução.

## Segurança

O protótipo é deliberadamente offline em relação à operação:

- sem Supabase;
- sem chaves;
- sem Calendar;
- sem Windsor;
- sem GitHub runtime;
- sem escrita externa;
- dados 100% fictícios dentro do próprio HTML.

Abra `v4/index.html` por um servidor HTTP estático para revisar a interface. As regras oficiais continuam sendo Mapa + Skills atuais até migração formal.
